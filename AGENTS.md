# 🤖 AGENTS.md

## 🎯 Goal
We are transforming a static workout site into a Web3 NFT Platform using a "Baby Steps" approach.

## 📋 Process & Rules

1.  **Check the Backlog First:**
    - Before starting any task, read `BACKLOG.md`.
    - Identify which "Phase" and "Feature" you are working on.

2.  **Behavior Driven Development (BDD):**
    - All new features must be defined in `BACKLOG.md` using the `GIVEN`, `WHEN`, `THEN` format before implementation.
    - If you add a new feature, add it to the Backlog first.

3.  **Update Documentation:**
    - When you complete a task, change `[ ]` to `[x]` in `BACKLOG.md`.
    - If you discover new requirements, add them to the appropriate Phase in `BACKLOG.md`.

4.  **Tech Stack (Target):**
    - **Framework:** Next.js 14 (App Router)
    - **Styling:** Tailwind CSS + shadcn/ui
    - **Language:** TypeScript
    - **State:** Zustand
    - **Icons:** Lucide React

## 🚀 Deployment
- The project is deployed to GitHub Pages.
- Ensure `npm run build` passes before submitting.
